# Replacement & Recovery Workflows

Workflows: IDENTIFY, CAPTURE, VERIFY, COMPARE, COMPATIBILITY_CHECK, MIGRATE, BENCH_VALIDATE, RESTORE, RECOVER.

Failed compatibility blocks state-changing phases. Source capture is immutable. Physical writes are hard-denied. Simulation does not set authorized_write.

CLI: `ecugate-platform` (profiles, modules, inspect, validate-manifest, capture-report, verify-backup, compatibility, simulate-workflow, esp32-s3).
